EIRON STOCK V2 • PWA iPhone

1. Publique esta pasta em qualquer hospedagem estática HTTPS.
2. Abra o index.html pelo endereço HTTPS no Safari do iPhone.
3. Toque Compartilhar → Adicionar à Tela de Início.
4. O EIRON STOCK abrirá em modo aplicativo e poderá funcionar offline após o primeiro acesso.

Observação: esta versão ainda salva os dados localmente no aparelho. A próxima etapa é sincronização com Supabase.
